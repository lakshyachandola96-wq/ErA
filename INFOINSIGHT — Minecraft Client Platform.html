    Installation Guide
    Make sure you have Java 17 or later installed on your system.
    Install the appropriate mod loader (Fabric / Forge) for your Minecraft version.
    Download the client JAR or ZIP file from the download button above.
    Place the file in your Minecraft mods folder (or extract ZIP to your .minecraft folder).
    Launch Minecraft with the correct profile and enjoy.
